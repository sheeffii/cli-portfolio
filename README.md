# Shefqet Salihu | DevOps Engineer Portfolio

Welcome to the repository for my personal portfolio, accessible at [shefqet.cloud](https://shefqet.cloud).

## Tech Stack
* **Frontend:** React, Vite, Tailwind CSS
* **CI/CD:** GitHub Actions
* **Hosting:** GitHub Pages with custom domain routing

## What’s new (upgrades)
- **Ctrl+K command palette**: quick navigation + actions + open project case studies
- **Terminal**: mini-shell feel with `cd`, `ls`, `cat`, `pwd`, `neofetch` and Tab autocomplete
- **Project case studies**: click any project card to open a dialog with
  - interactive architecture flow
  - highlights + outcomes (credibility)
  - tech stack tags + GitHub link
- **Blog**:
  - `/blog` listing with featured post + filters
  - `/blog/:slug` post pages with Markdown, TOC, and share (copy link)
- **Appearance menu in navbar**: theme + terminal skins + “skip boot next time” + reduce motion
- **Reduced-motion support**: animations/transitions respect OS accessibility settings
- **Incident simulator**: a fun, recruiter-friendly DevOps mini demo (also accessible from Ctrl+K)
- **SEO/share**: OG image, JSON-LD, sitemap + robots, nicer 404

## Local Development
To run this project locally:
1. Clone the repository
2. Run `npm install`
3. Run `npm run dev`
